| ##  Indgreb i en ligevægt                          | **Udstyr:**                                        |
|                                                    |                                                    |
|                                                    | 7 Mikroreagensglas                                 |
|                                                    |                                                    |
|                                                    | Holder                                             |
|                                                    |                                                    |
|                                                    | 50 mL bægerglas                                    |
|                                                    |                                                    |
|                                                    | 2 stk små bægerglas eller banan-flueglas           |
|                                                    |                                                    |
|                                                    | Elkeddel                                           |
|                                                    |                                                    |
|                                                    | **Kemikalier:**                                    |
|                                                    |                                                    |
|                                                    | 0,1 M Fe(NO~3~)~3~                                 |
|                                                    |                                                    |
|                                                    | KSCN - fast                                        |
|                                                    |                                                    |
|                                                    | 0,1 M KSCN                                         |
|                                                    |                                                    |
|                                                    | 0,1 M AgNO~3~                                      |
|                                                    |                                                    |
|                                                    | 0,002 M KMnO~4~                                    |
|                                                    |                                                    |
|                                                    | Is                                                 |
+----------------------------------------------------+                                                    |
| **Formål:**                                        |                                                    |
|                                                    |                                                    |
| Formålet med dette forsøg er at undersøge, hvordan |                                                    |
| en reaktion i ligevægt opfører sig ved forskellige |                                                    |
| ydre indgreb og eftervise Le Chateliers princip.   |                                                    |
| Reaktionen du undersøger i dette forsøg, er mellem |                                                    |
| jern(III)ioner (Fe^3+^) og thiocyanat-ioner        |                                                    |
| (SCN^-^) og det dannede kompleks FeSCN^2+^.        |                                                    |
+:===================================================+:===================================================+
| **Teori:**                                                                                              |
|                                                                                                         |
| Le Chaterliers princip beskriver, at en kemisk ligevægt vil forsøge at mindske indvirkningen af ydre    |
| indgreb. F.eks. ved tilførsel af varme vil reaktionen forskydes i den retning, der forbruger varme      |
| (*endoterm retning*), ved tilførsel af mere stof vil reaktionen forskydes i den retning, der forbruger  |
| dette stof og ved volume-forøgelse vil reaktionen forskydes i den retning, hvor der er flest            |
| molekyler/ioner.                                                                                        |
|                                                                                                         |
| I dette forsøg er det ligevægten mellem jern(III)ioner(Fe^3+^), thiocyanationer(SCN^-^) og det dannede  |
| kompleks FeSCN^2+^, der undersøges                                                                      |
|                                                                                                         |
| Fe^3+^(aq) + SCN^-^(aq) ⇌ FeSCN^2+^(aq)                                                                 |
|                                                                                                         |
| > (Orange) (Farveløs) (Rød)                                                                             |
+---------------------------------------------------------------------------------------------------------+
| **Fremgangsmåde:**                                                                                      |
|                                                                                                         |
| 1.  Fyld ca. 10 mL demineraliseret vand i en 50 mL konisk kolbe og tilsæt ca. 10 dråber 0,1 M           |
|     Fe(NO~3~)~3~ og ca. 10 dråber 0,1 M KSCN og omrør.                                                  |
|                                                                                                         |
| 2.  Fyld 6 mikroreagensglas 1/3 op med ligevægts-blandingen fra punkt 1.                                |
|                                                                                                         |
| 3.  ![C:\\Users\\jm\\AppData\\Local\\Microsoft\\Windows\\Temporary Internet                             |
|     Files\\Content.Word\\20131212_103530_resized.jpg](media/image1.jpeg){width="2.303472222222222in"    |
|     height="1.6201388888888888in"}Undersøg hvad der sker med ligevægten, når du øger koncentrationen af |
|     et udgangsstof ved at tilsætte et krystal KSCN (som indeholder SCN^-^)                              |
|                                                                                                         |
| 4.  Undersøg hvad der sker, når man tilsætter 0,1 M sølvnitrat til 0,1M KSCN, dette gøres i et ekstra   |
|     mikroreagensglas.                                                                                   |
|                                                                                                         |
| 5.  Undersøg hvad der sker med ligevægten når du tilsætter et par dråber 0,1M AgNO~3~ til               |
|     ligevægtsblandingen                                                                                 |
|                                                                                                         |
| 6.  Undersøg hvad der sker, når man køler eller varmer på reaktionen ved at komme et glas i varmebad og |
|     et i kuldebad. I hvilken retning er reaktionen exoterm?                                             |
|                                                                                                         |
| 7.  Fyld ca. 2 mL 0,002M KMnO~4~ ned i to 5mL bægerglas og husk at væsken skal stå lige højt i de to    |
|     glas. Stil de to glas på hvidt papir og tilsæt 3mL vand til det ene glas. Betragt begge glas fra    |
|     oven og fra siden og noter dine observationer.                                                      |
|                                                                                                         |
| 8.  Gentag punkt 7 med ligevægtsblandingen. Hvad sker der med ligevægten ved volume-forøgelse?          |
+---------------------------------------------------------------------------------------------------------+
| **Efterbehandling:**                                                                                    |
|                                                                                                         |
| 1.  Hvordan kan man se, om ligevægten bliver forskudt mod højre eller venstre?                          |
|                                                                                                         |
| 2.  Diskuter alle forsøgsresultaterne og inddrag Le Chateliers princip.                                 |
|                                                                                                         |
| 3.  Opskriv ligevægtsloven for reaktionen.                                                              |
