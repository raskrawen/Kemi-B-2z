
# Tydelige krav og rammer


# Ansvar
Eleverne skal stilles til ansvar for deres aktiviteter og deltagelse i undervisningen.
Det kan ske gennem aflevering af produkt fra modulet.

# Ansvar for lektielæsing
Eleverne skal jævnligt have mulighed for at blive testet i deres lektielæsning. 
Det kan ske hjemme gennem små tests, quizzer eller spørgeskemaer. 
Det kan ske i modulerne gennem små skriftlige opgaver, quizzer, spørgeskemaer,mundtlige spørgsmål i klassen eller deltagelse i gruppearbejde.


# Test og evaluering
Eleverne skal have mulighed for at blive testet og evalueret i deres læring.
Flere små tests undervejs i forløbet kan give eleverne mulighed for at reflektere over deres læring og justere deres indsats. Det kan også give underviseren mulighed for at tilpasse undervisningen efter elevernes behov.
